# mmirzakhani93.github.io

Professional portfolio website for Mohammad Mirzakhani, Java Backend Engineer.

## Deploy on GitHub Pages

1. Replace the existing repository contents with:
   - `index.html`
   - `styles.css`
   - `favicon.svg`
2. Commit and push to the `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Set the source to **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://mmirzakhani93.github.io/`

## Optional: add a CV download

Place your PDF in the repository as `Mohammad_Mirzakhani_CV.pdf` and add this button in `index.html`:

```html
<a class="button secondary" href="Mohammad_Mirzakhani_CV.pdf" target="_blank">Download CV</a>
```
